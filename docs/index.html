    The real app in two minutes

    A captioned walkthrough at phone size. Claude Code recorded it by driving the real app with Playwright against a simulated Sonos speaker, so no hardware was needed.

    1. Now PlayingLive track info, album art, skip and pause.
    2. Queue and full-screen playerBackground colours are pulled from the album art.
    3. Live ControlsVolume, bass, treble and sub gain in real time.
    4. Speaker groupingGroup rooms in one tap, then set each speaker's level.
    5. TV audioThe view switches when the TV turns on. Speech Enhancement, Night Mode and the sub change live.
    6. Profiles, schedules, settingsBuild a "Late Night TV" profile, schedule it, and check the activity log.

    The video has no sound. Song and artist names come from the simulated speaker.

    Feature tour

    Built for the room, not the playlist

    The Sonos app is good at music. This is for the rest of a home theater: consistent levels, dialogue you can hear at night, and settings that apply themselves. Pick a feature to see the screen.

    Signal flow

    How a tap reaches the speaker

    Everything stays on the local network. Nothing is sent to the cloud. Use the remote at the top and watch a command travel.

    The controller and the API bridge both run as background services that start at boot: launchd daemons on macOS, Task Scheduler on Windows. Profiles, schedules and settings live in a local JSON file, so they survive restarts and port changes.

    How it was built

    Built entirely with Claude Code

    I brought the AV knowledge and decided what the app should do. Claude Code wrote every line of the software.

    Each feature started as a plain-language request. Claude Code read the codebase, wrote the change, ran it, and checked the result in a real browser before committing. Even this page, the interactive room and its sound came from the same kind of conversation.

    • The React interface, AMOLED theme and all components
    • The Node server that proxies the Sonos API and stores settings
    • One-command installers for macOS and Windows, set up as boot-time services
    • A simulated Sonos speaker, so features can be tested without hardware
    • An automated pipeline that recorded the demo video and screenshots
